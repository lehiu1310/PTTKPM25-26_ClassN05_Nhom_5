# Design

Thư mục này chứa tài liệu thiết kế của ứng dụng Monex.

## Danh Sách

| Tài liệu | Mô tả |
| --- | --- |
| `Architecture.md` | Thiết kế kiến trúc tổng quan, các layer và luồng dữ liệu |
| `Architecture_Model.drawio` | Sơ đồ kiến trúc dạng draw.io |
| `Program_Design.md` | Thiết kế chương trình, module và chức năng |
| `Data_Design.md` | Thiết kế dữ liệu, thực thể và cấu trúc lưu trữ |
| `Sketches/monex_mobile_wireframe.svg` | Sketch/wireframe giao diện chính của app |

## Ghi Chú

Các file `.drawio` có thể mở bằng draw.io/diagrams.net để xem và chỉnh sửa sơ đồ.
