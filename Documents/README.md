# Documents

## Danh Sách Tài Liệu

| Tài liệu | Mô tả |
| --- | --- |
| `Project_Plan.md` | Kế hoạch dự án, tiến độ, rủi ro, tiêu chí hoàn thành |
| `SRS.md` | Đặc tả yêu cầu phần mềm, tác nhân, chức năng, phi chức năng và tiêu chí kiểm thử |
| `SRS_UseCase.drawio` | Sơ đồ use case hỗ trợ phần phân tích yêu cầu |
| `Weekly_Report.md` | Báo cáo công việc theo từng tuần |
| `Project_Report.md` | Báo cáo tổng hợp dự án |
| `Baocao_Monex.docx` | Báo cáo học phần mới nhất của ứng dụng Monex |
| `Monex_Presentation.pptx` | Slide trình bày dự án |
| `Git_Requirement_Checklist.md` | Checklist đối chiếu repository với yêu cầu Git của giảng viên |
